# 島嶼烽火：臺灣 1661–1930

*Contested Shores: Taiwan 1661–1930*（有英文版：設定 → 語言）

以臺灣 1661 到 1930 年間的戰爭為主題的瀏覽器即時戰略遊戲，共六個戰役，各方都有自己的立場與代價。

首部戰役「大員之圍 1661」以 1661–1662 年熱蘭遮城圍城為主題，四章，鄭氏與荷蘭東印度公司（VOC）兩方都能玩；台江內海的潮汐、要塞的交叉火力、瘴癘與補給、原住民各社與漢人移民的立場，都會左右戰局。

另有五個戰役：「施琅攻臺 1683」（澎湖海戰：八罩、娘媽宮兩章，東寧與清朝水師；尾聲「東寧」）、「牡丹社事件 1874」（石門之役、三路進剿兩章，排灣族諸社與日本出兵軍）、「清法戰爭 1884」（滬尾、月眉山、澎湖三章，清軍與臺灣鄉勇、法國遠東艦隊）、「乙未戰爭 1895」（澳底、桃竹苗、八卦山、臺南四章，臺灣民主國與各地義軍、日本軍；第 5 章「太魯閣（1914）」）、「霧社事件 1930」（起事、馬赫坡兩章，賽德克族德固達雅群六社與臺灣總督府），除「東寧」外都是兩方都能玩（見下方）。

線上試玩：<https://jamesleecy.github.io/contested-shores/>

指令面板（右下 3×4）每格右上角的字母是熱鍵。右上角的潮汐圓環、遊戲日與章節計時決定你的每一個決策：

- **潮汐**：漲潮時戎克船可走淺水道（鹿耳門），退潮時船會擱淺、步兵可以涉水。
- **要塞**：兩座以上稜堡覆蓋同一目標時傷害 +25%。正面強攻代價極高；挖壕溝、架砲台（火砲射程 +2）、搶制高點才是正解。
- **時間**：鄭軍每天都會因瘴癘減員；VOC 靠庫存、海上補給（主航道被封鎖就不來）與援軍。
- **島上不只兩方**：選取「社」或移民的糖廍可打開外交面板：贈禮、招撫、請求戰士。好感 ≥ 80 且領先對手 20 才會結盟，跌破 20 會轉為敵對並派人襲擾。

主選單也有兩種沙盒（兩軍對峙、從一座營寨開始經營），以及圖鑑、設定（音量、捲動速度、色盲模式）、讀取／匯入存檔。

## 施琅攻臺 1683：澎湖海戰

1683 年夏，清朝福建水師提督施琅率兩百多艘戰船進攻東寧（明鄭）的門戶澎湖，守將劉國軒以沿岸砲城與船隊迎戰。兩章都是海戰，**風向**是新的關鍵：帆船順風最多快 45%、逆風最多慢 45%，右上角的風向標顯示目前的風。

- **第 1 章 八罩（7 月 10 日）**：北風，清軍逆風北上。東寧在砲城射程內列陣迎擊；清軍要擊沉 20 艘東寧戰船才算擊破，損失 15 艘或施琅的旗艦受重創就退回八罩（史實：施琅右眼中彈，清軍初戰失利）。
- **第 2 章 娘媽宮（7 月 16 日）**：清晨西北風對東寧有利，開戰 4 分鐘後轉南風（據部分記載）。清軍分三路，要摧毀娘媽宮砲城並讓 12 艘船駛入內港；東寧要守 12 分鐘（颱風季將至）、擊沉施琅的旗艦，或讓清軍損失 26 艘。娘媽宮危急時劉國軒會試圖經吼門脫離，他的旗艦沉沒比史實更差。
- **尾聲 東寧（1683 年 7–10 月）**：只能從東寧方玩。3 分鐘內在朝議中選擇：**降清**（史實）；**南下呂宋**：殘破的船隊要在 5 分鐘內讓 6 艘船突破主航道、鹿耳門與南方巡哨，駛到南方外海；**死守承天府**：清軍在禾寮港登陸，守軍會陸續棄城，要守住 8 分鐘。不選則由馮錫範拍板投降。
- **五點梅花**：五艘以上的船合攻同一艘時傷害 +30%。
- 敘事上這是清朝征服東寧的戰爭，不以現代政治立場評價；施琅的評價放在圖鑑的史料爭議。規劃與查證見 [docs/CAMPAIGN_PENGHU_1683.md](docs/CAMPAIGN_PENGHU_1683.md)。

## 牡丹社事件 1874

1874 年 5 月 22 日，日本以 1871 年琉球船難者遇害為由出兵台灣南部，日軍沿四重溪進攻石門；牡丹社頭目阿祿古率各社戰士據守兩側山壁。本作把日方定位為未經清朝同意、侵入排灣族土地的出兵者，但遊戲設計保持中立：兩方各有清楚的目標，比的是誰能達成。

- **日本出兵軍**：8 分鐘內肅清兩側高地（守軍少於 3 人），並讓 6 人通過峽谷。步兵射程長、射速快、會分梯隊增援；但看不見藏在山裡的人，爬峭壁很慢，每天還有人倒在瘧疾下。
- **排灣族諸社**：守住高地 8 分鐘，或讓日軍死傷到無力再戰。熟悉山路（山地移動快得多）、在山林與高地中隱匿（敵人 1.5 格內才看得見；開火的硝煙會在 5 格內暴露位置 1 秒）、從高處射擊時對方仰攻傷害減半。高士佛社與女仍社的戰士會陸續趕到。
- 族人的撤離是劇情演出，不會成為攻擊目標。結局評價依史實比較：石門失守是「史實」，阿祿古存活則記在結果中。

**第 2 章 三路進剿（6 月 1–3 日）**：日軍分三路入山，攻向牡丹社、女仍社、高士佛社。

- **日本出兵軍**：10 分鐘內佔領三社（社內 5 人、沒有排灣戰士，守住 45 秒）。三路各自推進，瘧疾比 5 月更嚴重。
- **排灣族諸社**：在山路兩側的高地伏擊、日軍逼近就退入深山，或在部落周圍的山林騷擾佔領者，拖過 10 分鐘，或讓日軍兵力跌破 20。也要親手把各社族人帶往東北深山：日軍佔領時族人還在社內，評價會比史實更差。
- 若阿祿古在石門之役存活，第 2 章他會再次登場。

## 清法戰爭 1884–85

法國為了越南與清朝開戰，艦隊來到臺灣北部奪取基隆煤礦作為談判籌碼。本作把法方定位為列強在東亞的擴張，遊戲機制保持中立；清方除了劉銘傳的湘淮勇營，也有臺灣本地的鄉勇、霧峰林家的棟軍與張李成的土勇。滬尾之役後法軍遺體被斬首示眾等事，只在史實卡與圖鑑以文字交代。

- **第 1 章 滬尾（1884 年 10 月）**：法艦先轟擊砲台，2:30 時水兵登陸；水兵的子彈有限，鄉勇與土勇藏在樹籬間伏擊。法軍要攻佔紅毛城一帶的高地，清方守住或把登陸部隊打到不足 8 人（史實：法軍退回船上）。紅毛城（當時的英國領事館）是不能攻擊的地標。
- **第 2 章 月眉山（1885 年 1–3 月）**：法軍攻紅淡山、月眉山的山脊，霍亂與傷寒持續減員，5:00–7:00 大雨讓槍砲難以命中，7:00 法軍從東岸迂迴。山脊失守後清軍退守基隆河南岸的暖暖（史實的僵持）。
- **第 3 章 澎湖（1885 年 3 月）**：沿用 1683 的澎湖地圖，換成 1885 年的砲台；不受風向影響的蒸汽戰艦在灣口砲擊，陸戰隊登陸攻取媽宮。
- 規劃與查證見 [docs/CAMPAIGN_SINOFRENCH_1884.md](docs/CAMPAIGN_SINOFRENCH_1884.md)。

## 乙未戰爭 1895

1895 年清朝依《馬關條約》割讓臺灣，臺灣的官紳成立臺灣民主國抗拒割讓，日軍從澳底登陸，一路打到臺南。本作把日方定位為依條約以武力佔領，遊戲機制保持中立；臺灣方不是單一勢力：民主國的清軍舊部、劉永福的黑旗軍與各地義軍各有表現。日軍對平民的報復只在史實卡與圖鑑以文字交代，不在畫面上演出。

- **第 1 章 澳底**：日軍要摧毀獅球嶺砲台並在基隆站穩；臺方在三貂嶺、瑞芳、獅球嶺層層固守。唐景崧出逃時，臺北的守軍會一哄而散。
- **第 2 章 桃竹苗**：**補給線**：日軍離兵站或糧車超過 9 格，士氣每秒下滑。新竹要等糧車送到、建立兵站，才能再攻苗栗；客家義軍躲在路旁丘陵，專打運糧隊（隆恩埔）。
- **第 3 章 八卦山**：**夜戰**：開場視野縮小，天亮恢復；涉水渡大肚溪時受到的傷害增加。黑旗軍與義軍的南北聯軍據守八卦山的克魯伯砲台。
- **第 4 章 臺南**：日軍三路合圍（嘉義南下、布袋嘴與枋寮登陸），疫病每天削弱兵力。劉永福可以選擇「內渡」結束本章（史實結局）；他戰死則比史實更差。
- **第 5 章 太魯閣（1914）**：1895 年後，山地的原住民各族又抵抗了近二十年。本章是其中最大的一戰：日方軍隊從合歡山、警察從新城兩路進攻立霧溪流域的太魯閣族。日方要在 15 分鐘內佔領古白楊、卡拉寶、沙卡亨三社；太魯閣族在部落周圍的台地射擊、日軍逼近就退入山中，拖過時限或讓日方兵力跌破 20。從臺灣方選這一章會操作太魯閣族、從日方選則操作總督府。
- 規劃與查證見 [docs/CAMPAIGN_YIWEI_1895.md](docs/CAMPAIGN_YIWEI_1895.md)。

## 霧社事件 1930

1930 年 10 月 27 日，馬赫坡社頭目莫那・魯道率賽德克族德固達雅群六社起事。本作把日方定位為殖民統治者，起事的原因（強迫勞役、欺壓、敬酒風波）在過場與圖鑑中交代；遊戲機制保持中立。霧社公學校運動會上對日本平民的殺戮、族人的集體自縊與第二次霧社事件，都只在史實卡與圖鑑以文字交代，不在畫面上演出；公學校只以地標出現、不能攻擊。

- **第 1 章 起事（10 月 27–29 日）**：族人攻下各駐在所，每攻下一處就有持刀的勇士換上奪來的步槍，子彈也會增加；攻下霧社分室與至少 4 處駐在所後，要守住霧社到 12 分鐘。日方守住分室，或在族人攻下霧社後以眉溪趕來的救援隊奪回。
- **第 2 章 馬赫坡（10 月 31 日–11 月）**：日方的軍隊、警察與道澤群戰士分路進攻塔羅灣、馬赫坡與岩窟。**空襲**：地上出現紅圈，數秒後落彈，在森林或山中可以減傷。族人的子彈有限，用完只能近戰；第 1 章攻下霧社，第 2 章會多 6 名槍手與 400 發子彈。毒氣只在圖鑑交代史料爭議。
- 規劃與查證見 [docs/CAMPAIGN_WUSHE_1930.md](docs/CAMPAIGN_WUSHE_1930.md)。

## 難度與提示

- 1683 年以後的章節，難度會縮放電腦方的部隊人數（簡單 ×0.75、困難 ×1.25，開場與增援都算）；英雄、族人與糧車人數不變。
- 每章第一次遇到新玩法（風向、山林隱匿、補給線、夜戰、空襲……）時，右上角會出現說明卡，同一個瀏覽器只顯示一次。

## 史實說明

戰役依 1661 年 4 月鄭軍穿過鹿耳門、5 月普羅民遮城投降、夏秋 Caeuw 援軍反攻失敗、1662 年 1 月烏特勒支堡失守到 2 月 1 日和約的順序展開。每章結束會顯示「史實上發生了什麼」，圖鑑記錄每個單位、建築、人物與地點的史實背景、遊戲中的取捨與參考來源，並標示史料爭議（例如叛逃者 Radis 一事僅見於荷方記載）。

遊戲依[規劃書](島嶼烽火：臺灣%201661–1930%20世界觀與設計規劃書.md)第 2.4 節的原則撰寫：兩方都能玩、兩方的敘事都包含代價；原住民各社有名字與自己的選擇；不呈現虐殺；爭議會標示。審查紀錄見 [docs/CONTENT_REVIEW.md](docs/CONTENT_REVIEW.md)。

主要參考：1895 年部分：維基百科「乙未戰爭」（中文）、"Japanese invasion of Taiwan (1895)"（英文）。1683 年部分：維基百科「澎湖海戰」（中、英文）、「鄭克塽」（中文）、施琅《靖海紀事》（經條目轉引）。1914 年部分：維基百科「太魯閣戰爭」（中文）、"Truku War"（英文）。1930 年部分：維基百科「霧社事件」（中文）、"Musha Incident"（英文）。1884 年部分：維基百科 "Battle of Tamsui"、"Keelung campaign"、"Pescadores campaign (1885)"（英文）、「清法戰爭」（中文）。Tonio Andrade, *Lost Colony*（2011）、Wikipedia: Siege of Fort Zeelandia、Atlas of Mutual Heritage、揆一《被遺誤的台灣》。1874 年部分：Edward H. ## 開發

需要 Node.js 22 以上。

```bash
npm install
npm run dev          # 開發伺服器
npm run validate     # 資料與地圖驗證
npm test             # 單元測試（Vitest）
npm run test:e2e     # 端到端測試（Playwright，需先 npm run build）
npm run build        # 輸出 dist/
npm run battle -- --chapter 2 --runs 20   # 無頭 AI 對戰統計
```

網址參數：`?chapter=1..4&faction=voc&difficulty=easy|normal|hard&skipCutscenes`、`?mode=sandbox`、`?mode=economy`。

### 架構

- `src/sim/`：純 TypeScript 的確定性模擬（20 Hz 固定步長、種子化亂數、只能經由指令改變狀態），不碰 DOM，可在 Node 中無頭執行與重播。ESLint 禁止在這裡使用 `Math.random`、`Date.now` 與 DOM。
- `src/render/`：PixiJS 等角繪製（只讀模擬狀態）。
- `src/ui/`：DOM 介面、輸入、選單、存讀檔、音效。
- `data/`：所有數值（單位、建築、科技、規則、地圖、劇本、圖鑑）都在 JSON 裡，程式不寫死數值；`scripts/validate-data.ts` 會檢查 schema 與交叉參照。
- `docs/DECISIONS.md`：規格沒寫到或前後不一致時的實作決策；`docs/PROGRESS.md`：各階段進度與驗收結果。

部署：推送到 `main` 時 GitHub Actions 依序執行資料驗證、地圖驗證、lint、單元測試、建置、Playwright 冒煙測試，全部通過才發佈到 GitHub Pages。
