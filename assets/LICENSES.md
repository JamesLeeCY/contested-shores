# 素材授權

| 素材 | 來源 | 授權 |
| --- | --- | --- |
| 全部音效與音樂（`src/ui/audio.ts`） | 執行時以 Web Audio 程式合成，無錄音或第三方檔案 | 本專案原創 |
| 地形圖塊 `assets/tiles/terrain.png` | `scripts/gen-map.ts` 程式產生的純色菱形 | 本專案原創 |
| 單位、建築、特效圖形（`src/render/`） | PixiJS 向量繪製 | 本專案原創 |
| 過場插圖 | CSS 漸層佔位圖 | 本專案原創 |
| 字型 | 使用者系統字型（Noto Sans TC／微軟正黑體／蘋方） | 不隨專案散布 |
