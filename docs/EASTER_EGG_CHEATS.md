# 彩蛋與密技：規劃

狀態：已完成（2026-10-27）。程式在 `src/sim/cheats.ts`（密技與效果）與 `src/ui/cheat-input.ts`（輸入框）；測試在 `tests/cheats.test.ts` 與 `tests/e2e/cheats.spec.ts`。

致敬《世紀帝國2》（1999）的密技 `how do you turn this on`：在聊天框輸入後出現一台裝機槍的藍色跑車。參考：聯合新聞網〈世紀帝國2密技 how do you turn this on〉https://tech.udn.com/tech/story/123154/7043959

## 一、已決定（2026-10-27）

1. **全部開放**：所有章節、沙盒、教學都能輸入；以「作弊」標記與不記評價區隔。
2. **兩台車都做**：致敬原版的藍色跑車，加上在地化的發財車。
3. **其他密技一起做**：資源、開圖、瞬間建造。

## 二、輸入方式

- 電腦：遊戲中按 Enter 開一行輸入框，Enter 送出、Esc 關閉；輸入框開著時快捷鍵暫停作用。
- 手機：在右上角的時鐘面板 3 秒內連點 5 下，開同一個輸入框（遊戲中沒有暫停選單，改用時鐘面板）。
- 比對前去掉前後空白、轉小寫、合併連續空白。輸入正確會跳出提示並播放喇叭聲；輸入錯誤則什麼都不發生。
- 指令走佇列：`{ type: 'cheat'; owner; code }`，由模擬執行，所以存檔、重播與確定性都不受影響。輸入框只送出已知的密技代號，不送原始文字。

## 三、密技表

| 輸入 | 代號 | 效果 |
|---|---|---|
| `how do you turn this on` | `cobra` | 在玩家主建築（沒有就找英雄或第一個單位）旁生出藍色跑車 |
| `發財啦` | `truck` | 生出發財車 |
| `滷肉飯` | `grain` | 糧食 +1000 |
| `阿里山` | `wood` | 木材 +1000 |
| `火藥庫` | `powder` | 火藥 +1000 |
| `鹿皮` | `deerskin` | 鹿皮 +1000 |
| `marco` | `reveal` | 全圖開視野（再輸入一次關閉） |
| `aegis` | `instant` | 建造、生產、研究瞬間完成（再輸入一次關閉） |

章節沒有用到的資源（例如 1930 年沒有鹿皮）照樣加，只是用不到。

## 四、兩台車

| | 藍色跑車 `cobra_car` | 發財車 `fatsai_truck` |
|---|---|---|
| 外觀 | 亮藍色低底盤、兩條白色賽車條紋、車頂機槍 | 白色小貨車加藍色腰線，車斗架機槍、車斗側面寫「發財」 |
| 速度 | 約騎兵 3 倍 | 約騎兵 2 倍 |
| 血量 | 2000 | 2500 |
| 武器 | 機槍，射程 7，連射 | 機槍，射程 6，連射 |
| 特性 | — | 可載 4 名步兵（沿用 embark/unload） |
| 限制 | 不能採集、建造、進駐建築、上船；不佔人口，所以也不吃糧食（士氣照常影響） | 同左 |
| 聲音 | 出現或被選取時按兩聲喇叭 | 同左 |

- 兩台車的單位都標記為 `cheat`：AI 計算兵力比、`units_below` 等條件時不算進去，避免劇本觸發條件被車子卡住；被車子打死的單位照常計入。
- 圖鑑另開「彩蛋」分頁，不放進史實單位。說明文字：「本車不見於任何史料。向 1999 年的《世紀帝國2》致敬。」

## 五、作弊標記

- 第一次輸入有效密技時設旗標 `cheated:<owner>`，存檔一併保存，讀檔後無法清除。
- 結算畫面顯示「作弊」徽章；不寫入評價、不更新年表上的成績。
- HUD 右上角加一個小小的「作弊」標記，提醒玩家這局不計分。

## 六、需要改動的地方

- `src/sim/commands.ts`：新增 `cheat` 指令與處理。
- `src/sim/cheats.ts`（新檔）：密技代號 → 效果；`reveal` 與 `instant` 的開關狀態存在 world flags。
- `data/units.json`：兩台車的資料；`src/render/art.ts`：兩台車的繪圖。
- 生產與建造系統：`instant` 開啟時直接完成。視野系統：`reveal` 開啟時全圖可見。
- `src/ui/cheat-input.ts`（新檔）：輸入框、文字比對、手機入口。
- `src/ui/app.ts`：結算畫面的作弊徽章、不記評價；HUD 標記。
- `src/ui/codex.ts`：彩蛋分頁。
- i18n：中英文的提示、單位名稱與圖鑑文字。
- 測試：單元測試確認每個密技的效果、作弊後不記評價、重播結果一致；一個 e2e 測試在瀏覽器裡輸入 `how do you turn this on`，確認跑車出現。
